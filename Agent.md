# GPUChain agent setup

When a user gives you the GPUChain repository URL, follow [AGENTS.md](AGENTS.md). Clone or reuse the checkout, check for Node.js 24 or later, and run `npm start` to connect to the existing public testnet. The same command verifies the validator-operated network after Sites retires. The guide also covers explicitly opting in to validator duties or starting an independent local development network.
